เปิด Sheet

หลังแก้ไขโค้ด Apps Script ให้กด Deploy > New Deployment (หรือ Manage Deployment > Edit > New Version) ทุกครั้ง

บันทึกข้อมูลเข้า Sheet โดยตรง:

หากใน Sheet ยังเป็นตารางว่างเปล่า สามารถกดปุ่มนี้เพื่อส่งข้อมูลทั้งหมดเข้า Google Sheet ได้ทันที

ขั้นตอนการอัปเดตโค้ด Apps Script:

1. คัดลอกโค้ดด้านบนทั้งหมด ไปวางทับโค้ดเดิมใน Extensions > Apps Script

2. กด บันทึก (Ctrl+S)

3. กดปุ่ม การจัดทำให้ใช้งานได้ (Deploy) > การจัดทำให้ใช้งานได้ใหม่ (New deployment)

4. กำหนด "ผู้ที่มีสิทธิ์เข้าถึง (Who has access)" เป็น "ทุกคน (Anyone)" แล้วกด Deploy

5. นำ Web App URL มาวางที่ช่องด้านบน แล้วกด "บันทึกและซิงค์ข้อมูล"
